# Indi-course 🐍

This repository contains my solutions to programming tasks and exercises from various modules and courses. All scripts are written in Python.

## 📂 Structure

The project is organized into folders by topics and lessons:
* **1_basics** — basic concepts, arithmetic operations, and simple input/output.
* **2_strings_and_lists** — string manipulation, methods, and working with lists.
* **3_conditions** — conditional statements (if-elif-else), logical operations, and decision-making tasks.
